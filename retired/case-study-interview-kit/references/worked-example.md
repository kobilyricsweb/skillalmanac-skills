# Worked example

Synthetic example only.

Input:

- Context: `inventory planning service`.
- Outcome summary: `the retailer reduced stockouts`; source `account manager email`; no baseline, date, denominator, or customer quote.
- Interviewee: `retail operations lead`, organization name unknown.
- Audience: `operations managers`.
- Topics: prior process, implementation, observed change, limitations, quotation permission.
- Restrictions: `do not assume permission to name the retailer`.
- Time cap: 25 minutes.

Expected artifact:

The guide asks: “How did you manage stockouts before using the service?” “What changed, if anything, after implementation?” “Which period and locations are you describing?” “How was the change measured?” and “What other changes occurred at the same time?”

Follow-ups request the baseline, date range, number of locations, record source, exceptions, and implementation effort. A confirmation prompt asks the interviewee to verify whether “reduced stockouts” accurately reflects their experience. Permission prompts ask whether an exact quote, role, organization name, and edited excerpt may be used. The account-manager email is labeled a company-supplied assumption or lead, not a customer result. No quote or outcome is invented.

The timed agenda is marked as a planning estimate and totals no more than 25 minutes across opening, core questions, evidence follow-ups, and permission follow-ups. Extra probes are labeled optional/outside the core time box. The time allocation is not presented as measured feasibility.
