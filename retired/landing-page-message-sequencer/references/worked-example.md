# Worked example

Synthetic example only.

Input:

- Audience: `independent tutors`.
- Objective: `request a planning-template demo`.
- Messages: M1 `Tutors lose time rebuilding weekly plans` (problem); M2 `Reuse a weekly planning template` (approved promise); M3 `Three internal tutors completed the worksheet` (evidence statement); M4 `Save 30% of planning time` (provisional, no proof); M5 `Request a demo` (CTA).
- Assets: A1 `worksheet completion note`, location `internal pilot log`; no asset for M4.
- CTA: M5, destination `demo request form`, authorized for independent tutors.
- Visitor questions: `Is this for me?`, `What does it do?`, `Why trust it?`, `What should I do next?`.

Expected artifact:

1. Relevance: M1 answers whether the problem fits.
2. Mechanism/promise: M2 is approved wording, but evidence asset is not supplied; flag an unresolved reusability-evidence gap. A1 worksheet completion does not prove M2.
3. Evidence: M3 links to A1 and answers why trust it, with the internal scope retained.
4. Action: M5 follows, with CTA wording, destination, audience, authority, and prerequisites recorded.

M4 is rejected to a gap log because no supplied evidence supports the 30% figure. The artifact contains no HTML, layout instructions, SEO claim, or conversion prediction.
