Required fields: audience_profiles, approved_needs, profile_need_assignments, message_library, evidence_notes, exclusions, and allowed_ctas. Each profile, need, and message needs a stable ID; messages and needs also need text. profile_need_assignments must explicitly identify each profile_id/need_id pair to evaluate. Evaluate only those pairs; do not infer assignments from ordering, matching IDs, attributes, evidence, or CTA entries. Evidence notes should identify the message or claim they support. Exclusions may apply to profiles, needs, messages, or CTAs. A CTA is eligible only when listed for the relevant assigned pair and not excluded.

If a required field is absent, set artifact_status to provisional, list it in missing_required_fields, and provide only supported provisional rows. If profile_need_assignments is absent, do not create profile/need rows. If IDs, wording, or evidence conflict, retain the conflict and mark the affected candidate unresolved.

Output fields are artifact status, missing required fields, profile ID, need ID, message ID, match status, grounded rationale, evidence references, disqualifier, permitted CTA, and unresolved gap. Apply CTA exclusions before populating permitted_cta. A CTA exclusion does not by itself block an otherwise usable message. If no CTA was listed for the pair, set permitted_cta to null and record “CTA not supplied” in unresolved_gap. If CTAs were listed but all are excluded, set permitted_cta to null and identify the excluded CTAs and supplied reasons in unresolved_gap; do not describe any of them as permitted. If exactly one non-excluded CTA remains, report it. If multiple non-excluded CTAs remain, emit one otherwise identical candidate row for each permitted CTA and record any excluded alternatives in each row's unresolved_gap. A message exclusion still produces blocked status regardless of CTA permission.

A profile/need assignment is covered only when at least one evaluated row has match_status matched. Blocked, unmatched, and unresolved rows do not cover it. CTA permission remains separate from message coverage unless the supplied design expressly states that CTA availability is a condition of message use. List every assignment without a matched row in uncovered_needs using both profile_id and need_id so assignments sharing a need remain distinguishable.

Aggregate unmatched_messages by message ID across all evaluated rows: include an ID only when it has no matched row and at least one unmatched row. Exclude blocked-only and unresolved-only messages. Do not add inferred motivations, sensitive attributes, conversion estimates, market behavior, or validation beyond supplied evidence.
