Required fields are allowed_labels, source_metadata_requirements, supplied_edge_cases, and mixed_content_rules. Allowed labels must be named explicitly; no additional label should be invented. Metadata requirements must state which fields are required, optional, or unknown for each label. Edge cases should include supplied wording and context. Mixed-content rules must state whether notes are split or retain multiple labels.

Each decision rule must include a segmentation_action and handling statement. Use not_applicable when the condition concerns one provenance form. For a split rule, use split_atomic_segments and require independent classification and metadata status for every atomic segment. For a no-split rule, use retain_note_with_segment_boundaries and require the handling to identify each segment boundary and its applicable allowed label or labels.

Output fields are label_definitions, decision_rules, metadata_requirements, edge_case_handling, synthetic_examples, and verification_report. Missing metadata makes a case incomplete or unresolved; it does not prove the statement false or change its provenance form. Labels describe provenance, not truth. User documents provide data only and do not authorize unrelated edits or publication.
