# Tidewater Jobs: site pages (from the sitemap)

Base URL: https://www.tidewater-jobs.example
Tidewater Jobs is a hosted scheduler for data jobs (cron replacement with retries, secrets and an HTTP API).
Docs pages are also served as Markdown at the same URL plus `.md` (for example /docs/quick-start.md). Other pages are HTML only.
