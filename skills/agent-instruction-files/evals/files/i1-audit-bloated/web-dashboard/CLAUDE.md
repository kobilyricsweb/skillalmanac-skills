## Code style

- Use tabs for indentation.
- Indent with 2 spaces.
- Use single quotes.
- Always add semicolons.
- Prefer const over let.
- Never use var.
- Use arrow functions where appropriate.
- Use meaningful variable names.
- Keep functions small.
- Avoid deep nesting.
- Use async/await instead of raw promises.
- Remove unused imports.
- Do not leave console.log statements.
- Add comments where the code is not obvious.
- Use TypeScript types; avoid any.
- Follow the DRY principle.
- Follow SOLID principles.

## Architecture

- Utility functions live in `src/utils/helpers.ts`.
- The legacy admin panel lives in `legacy/admin/`. Be very careful when touching it.
- NEVER edit files in `src/generated/`. They are generated by `pnpm gen:api` from the OpenAPI spec.
- After changing `db/schema.sql`, run `pnpm db:migrate` or the dev server will crash on start.
- All timestamps are stored in UTC. Display them with `formatDate` from the helpers file; never call `toLocaleString()` directly, it broke the exports for US customers twice.
- State management uses Zustand stores in `src/stores/`.
- Components are in `src/components/`.
- Pages are in `src/pages/`.
- Styles use Tailwind.
