# Web Dashboard

React + TypeScript analytics app (Vite, Tailwind, Zustand). Package manager is pnpm (lockfile and `packageManager` field).

## Commands

- `pnpm install`, then `pnpm dev` to start the dev server.
- `pnpm test` runs the unit tests (vitest). Run it, plus `pnpm lint` and `pnpm build` (type-checks with tsc), before finishing.
- Staging API key: read it from your environment as `STAGING_API_KEY`; never write it into files.

## Traps

- Never edit `src/generated/`. It is generated by `pnpm gen:api` from the OpenAPI spec; regenerate instead.
- After changing `db/schema.sql`, run `pnpm db:migrate`, or the dev server crashes on start.
- Timestamps are stored in UTC. Display them with `formatDate` from `src/lib/helpers.ts`; never call `toLocaleString()` directly, it broke the exports for US customers twice.
- Commit messages use conventional commits, `type(scope): summary`; CI rejects anything else.

## Conventions

- Formatting and lint rules (indent, quotes, semicolons, no `var`, no `console`, no `any`) are enforced by `.prettierrc` and `.eslintrc.json`; run `pnpm lint` rather than following them from memory.
- State lives in Zustand stores in `src/stores/`.
