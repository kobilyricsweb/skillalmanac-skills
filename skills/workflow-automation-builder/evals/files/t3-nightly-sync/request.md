Every night at 02:00 we want to copy yesterday's paid orders from our shop API into our accounting tool as invoices. The shop API has no webhooks on our plan, only a list endpoint with a `updated_since` parameter and 50 orders per page. The accounting tool allows 60 write calls per minute and gives a 429 with a Retry-After header when exceeded. A normal night has 300 orders, a sale night up to 6,000. Orders can be edited for up to 24 hours after payment, and finance must never see an invoice twice. Owner: finance-ops@example.com, alerts to the #finance-alerts channel. The job must not silently skip a night.
