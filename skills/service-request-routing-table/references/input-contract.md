Required inputs are request categories, explicit routing conditions, precedence or override clauses, a role directory, and an approved fallback destination. Include definitions for urgency, location, exception, and unknown category when those terms appear. State whether one request may have multiple destinations. If overlapping rules lack precedence, mark the overlap ambiguous and do not choose. If the role directory omits a named destination, report the directory gap. If fallback is missing, unresolved requests remain unrouted. Output fields are: rule identifier; conditions; destination role; precedence; exception; fallback behavior; matched test request; and ambiguity or gap notes. Routing must be deterministic only where the supplied rules make it deterministic. Approval authority, staffing capacity, and external dispatch are outside this specification.
