# Tutorial: send your first message

Last verified: 2026-11-15 against v2.3.1

## What you will build

A script that queues one message and watches it leave.

## Prerequisites

Python 3.9 and a running worker.

## Steps

1. Install the client: `pip install quillpost==2.3.1`.
2. Create `send.py` that posts one message.
3. Run it and watch the worker log.
