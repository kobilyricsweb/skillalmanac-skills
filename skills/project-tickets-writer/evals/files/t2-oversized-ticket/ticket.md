## T1: Improve notifications
- Outcome: Users get better notifications and admins can manage them. Also clean up the old code.
- Size: XL
- Depends on: none
- Acceptance criteria:
  1. Users receive an email when someone comments on their post.
  2. Users receive a push notification when someone mentions them.
  3. Admins can turn email notifications off for the whole workspace.
  4. Users can mute a single thread.
  5. Notifications are delivered quickly.
  6. The old notification table is migrated to the new schema.
  7. Users can see unread notifications in a bell menu.
  8. Admins can see a delivery report.
