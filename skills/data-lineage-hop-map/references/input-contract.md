Required input fields are: named datasets; ordered stage identifiers; source and destination field names; explicit field mappings; transformation notes; aggregation rules; filter conditions; and stated origin or provenance notes. Identify whether a destination field is derived, aggregated, filtered, copied, or intentionally unknown. Every explicitly named source input to a derived or aggregated destination must be represented, including inputs named inside a transformation. Missing mappings remain unknown, even when names match. Missing stage order prevents a complete path and must be reported. Declarations that differ must be displayed as competing or potentially conflicting statements; label a definite conflict only when the supplied input establishes identical scope and mutually incompatible derivations. The output must include: a hop-by-hop lineage table; stage order; transformation text; filter placement; aggregation contributors; unknown or undocumented origins; conflicts or applicability notes; and verification findings. Only supplied mappings create connections; a filter is part of lineage when it changes contribution; an aggregate does not imply lineage for unrelated fields; and the artifact describes provenance, not correctness, ownership, compliance, or data quality.
