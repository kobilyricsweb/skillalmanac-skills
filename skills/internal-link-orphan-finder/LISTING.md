# Internal link orphan finder

## One line

Finds orphan pages, pages that sit more than three clicks deep, and broken internal links in a folder of HTML or Markdown files.

## What it does

The skill runs a standard-library Python script over one site folder. The script reads every `.html`, `.htm` and `.md` file, pulls out the relative links that point inside the folder, and builds a directed graph with one node per page. From that graph it reports pages that nothing links to, pages that have inbound links but no click path from the root index, pages more than three clicks from the index, and internal links whose target file does not exist. It also lists the five pages with the most inbound links so a reviewer can see where the internal link equity concentrates. The output is one JSON object, followed by a fixed report layout that the agent fills in from the counts. The script never writes into the scanned folder and refuses any `--out` path that would land inside it.

## When to use

Use it before a crawl review or a sitemap review, when a batch of new pages has gone live and you want to confirm each one is linked from somewhere reachable. It also fits a quarterly pass over a static site export, where broken relative links often appear after folders are renamed. A reviewer with a local copy of the HTML or Markdown source can run it without any server access.

## When not to use

It does not check external links, does not fetch live URLs, does not read sitemaps, and does not see links generated by client-side JavaScript or by a template engine that writes pages at build time. For those cases, use a crawler that runs against the deployed site. It also does not rewrite links or move pages; the report names the fix category and a person makes the change.

## Requirements

Python 3.9 or newer, with the standard library only. No network access, no installed packages, no environment variables. The site folder must hold an `index.html` or `index.md` at its top level, must stay under 2000 pages and 5000 files, and every page must be UTF-8 text no larger than 2 MB.

## Limits

- Only `href` attributes and Markdown link syntax are read. Links written by scripts, templates or client-side code are invisible.
- The depth threshold of three clicks is a working value chosen for this tool, not a published standard.
- Hidden folders (names starting with a dot) and symbolic links are skipped, so the page count can be lower than the file count on disk.
- The scanner resolves links against the file tree only. It does not know whether a page is published, redirected or blocked from crawling.
