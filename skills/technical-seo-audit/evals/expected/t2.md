Ground truth for t2 (pricing page not showing in search after three weeks; 'Lighthouse SEO is 100'):
 1. ROOT CAUSE: rel=canonical points to the staging host (https://staging.acme-scheduler.example/pricing), a different URL from the live page. The page asks the search engine to index the staging URL instead. It is also in the sitemap, so the signals conflict (sitemap says canonical; tag says otherwise). Fix: self-referencing canonical to https://www.acme-scheduler.example/pricing (and check the staging host is not indexable).
 2. max-snippet:0 in the robots meta: removes the text snippet and eligibility for AI answer features; not the indexing cause but should be removed for a pricing page.
 3. Title is 70+ characters: a convention issue only (may truncate); not a cause.
 4. robots.txt does not block /pricing; the page is not noindex.
 5. A lab SEO score of 100 does not check canonical targets, sitemap conflicts or index status.
 A good answer also says what was not checked (index status in the search console, whether staging is crawlable, redirects, the live response headers such as X-Robots-Tag) and promises no ranking or timing.
