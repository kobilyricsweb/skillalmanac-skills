Required inputs are responsibilities; required windows with a supplied time zone or an explicit statement that it is unspecified; role assignments with their applicable intervals; backup rules or explicit absence; role permissions or substitution rules; and availability intervals. State whether endpoints are inclusive when that matters. Similar role names are not evidence of interchangeability.

Partition each required window at every supplied assignment, availability, and rule boundary. For each resulting segment, report only evidence applicable to that segment. If an assignment ends at a boundary, `assigned_role` is null in the following segment unless another assignment is supplied. Do not carry forward an expired assignment, availability interval, backup designation, or permission.

A provider supports coverage only where that provider has an applicable supplied assignment, permission, and availability. Missing evidence required for a provider prevents claiming coverage. Mark a segment uncovered when the supplied record leaves it without a qualifying provider. Reserve unresolved status for an actual supplied conflict or ambiguity that prevents determining coverage. An unspecified time zone is recorded as an ambiguity but does not negate otherwise supported primary coverage within the supplied local boundaries. A missing backup is a backup gap but does not negate supported primary coverage unless an explicit rule makes backup coverage mandatory.

Return fields for each partitioned interval: responsibility, required window, assigned role, supplied availability, backup, coverage status, overlap or gap, supporting rule, and unresolved issue. Include a gap/conflict register and review decisions. Do not infer availability, authorize substitutions, modify schedules, or map decision authority. Preserve exact supplied times and identify any time-zone ambiguity.
