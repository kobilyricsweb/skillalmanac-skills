## Verb swaps

Replace a topic or mood word with a verb that leaves a visible result. The script rejects the left column as a leading verb.

| Vague start | Replace with |
|---|---|
| Work on the budget | Open the budget sheet and add this month's rent row |
| Think about the move | Write three reasons to move and three to stay in a note |
| Figure out the visa | List the three documents the visa page asks for |
| Review the contract | Highlight every date and every amount in the contract |
| Prepare the talk | Write the title and the three headings on a card |
| Research laptops | Open two shop pages and copy price and weight into a note |
| Plan the trip | Pick the dates and write them on the calendar |
| Organize the files | Move the files from Downloads into one folder named for the project |
| Get started | Put the first document on the screen and read its first page |
| Deal with the email | Reply to the email in one sentence or write "reply Fri" on a card |

## Splitting patterns

When a step is over 45 minutes, split along the first pattern that fits.

| Pattern | Split into |
|---|---|
| Gather, make, send | collect inputs, produce the thing, deliver it (three steps) |
| Decide something | list options in a note, check one fact per option, choose and write the choice |
| Write something | outline (headings only), write the section you know best, write the rest, read once and fix |
| Learn something | read one source and write three lines, do one worked example, do one on your own material |
| Phone call | write the three points and the number, make the call, note the outcome |
| Clear a space | one surface or one box per step, not the room |

## First-action shrink ladder

If the first action still feels like a wall, step down one rung at a time and stop at the first rung the user will do now.

1. Open the thing (file, folder, page, drawer).
2. Put the thing where the work will happen (desk, table, screen).
3. Write the first line, or touch the first item.
4. Set a 10-minute timer and do only that.

## Estimates

Take the user's guess. For work the user has never done, or that depends on another person's reply, add 50%. A step whose guess rounds above 45 minutes is split, not rounded down. An estimate of 5 minutes for a first action is fine; for any other step under 15 minutes, merge with the next.
