# Sources

Written in the editors' own words from these public pages. They were not re-fetched while drafting this version; re-read them at the next review, because export formats and Figma features change.

- Design tokens community group, format module draft (https://www.designtokens.org/tr/drafts/format/): the model of tokens as objects with `$value`, `$type` inherited from groups, aliases as `{path}`, and `$extensions` for tool-specific data. The `$modes` list used by the script is a skill convention layered on `$extensions`.
- Figma Help Center, guide to variables (https://help.figma.com/hc/en-us/articles/15339657135383): variable types (colour, number, string, boolean), collections, modes, aliases between variables.
- Figma Help Center, guide to auto layout (https://help.figma.com/hc/en-us/articles/360040451373): direction, spacing, padding, alignment, resizing (fixed, hug, fill), absolute position, wrap.
- Figma developer documentation, variables in the REST API (https://developers.figma.com/docs/rest-api/variables/): where an exported variable list comes from and its plan restrictions; confirm the current plan requirement before telling a user to use it.
- Figma Help Center, component properties (https://help.figma.com/hc/en-us/articles/5579474826519): variant, boolean, text and instance swap properties.
