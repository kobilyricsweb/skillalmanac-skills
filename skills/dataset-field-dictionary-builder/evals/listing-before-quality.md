# dataset-field-dictionary-builder

Unpublished original review draft. Editorial tier: free. No Platform Score or public sale.

## One Line

Builds a source-grounded dictionary for table fields and unresolved semantics.

## Audience

Analysts and data stewards inheriting undocumented tables.

## Deliverable

Field dictionary with provenance, constraints, null meaning, observations, and questions.

## Limits

No profiling statistics, contract enforcement, invented semantics, or remediation.

Scope distinction: Unlike dataset-field-profiler, this records supplied field definitions and unresolved semantics; it does not measure observed type/count distributions.
