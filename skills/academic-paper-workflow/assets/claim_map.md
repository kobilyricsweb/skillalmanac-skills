# Claim map

Copy this table into the working notes. One row per substantive claim. Fill "Supports" from the user's own notes on the source; never from memory.

| # | Claim (one sentence) | Section | Key | What the source supports (user's notes, page if given) | Status |
|---|---|---|---|---|---|
| 1 | | | `key` | | supported / own data / NEEDS SOURCE |

Status rules:
- `supported`: the key exists in the source file and the user's notes back the claim at this strength.
- `own data`: the author's result or reasoning; belongs in Methods, Results or the argument itself.
- `NEEDS SOURCE`: no source yet. Give the user the kind of source that would settle it (a survey, a primary text, a review) and search terms; name no specific work.

Gaps to report at the end: rows with NEEDS SOURCE, rows where the claim is stronger than the notes, and sources in the file with no row.
