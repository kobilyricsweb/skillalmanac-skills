# Paper structures and where citations belong

## Contents
- IMRaD (empirical and STEM)
- Humanities argument essay

Read only the section that matches the paper.

## IMRaD (empirical and STEM)

| Section | Job | Citations |
|---|---|---|
| Introduction | The gap: what is known, what is not, the question | Heavy. Every statement about prior work needs a key |
| Methods | What was done, enough to repeat it | Cite established instruments, datasets, software versions and protocols; the author's own procedure needs none |
| Results | What was found, without interpretation | Rarely; figures here are the author's own data |
| Discussion | What the results mean, limits, how they sit against prior work | Heavy when comparing with earlier findings; none for the author's own result |
| Conclusion or abstract | Restates, adds nothing new | No source first appearing here |

Check: every question in the Introduction is answered in Results or named as open in Discussion; nothing in Results is first explained in Discussion without being reported; limits are stated by the author, not left to a reader.

## Humanities argument essay

1. Opening: the question and why it matters, framed by one or two sources the user supplied.
2. Thesis: one arguable sentence the rest of the essay defends.
3. Body sections, each opening with a claim that serves the thesis, then evidence (primary sources, close reading) and the secondary literature it answers or departs from.
4. Counter-argument: the strongest objection, taken from a source where possible, and the reply.
5. Conclusion: what follows from the thesis; no new evidence.

Primary sources (archives, minutes, texts) need entries too: ask the user how they want them recorded. Page, chapter or folio numbers come from the user's notes only.

## Literature review

Organise by theme or by debate, not source by source. For each theme: what sources agree on, where they differ, and what remains unsettled. Each source appears where it advances a point, so an uncited-source finding usually means a source has no job yet.

## Claim types and what each needs

| Claim type | Needs |
|---|---|
| Fact from prior work (a rate, a date, a finding) | A key, and the user's note that the source says it |
| Interpretation of a source | The key, and a quotation or page the user supplied |
| Common knowledge in the field | Usually nothing; if unsure, ask the user or the supervisor |
| The author's own data or reasoning | Nothing; keep it in Methods, Results or the author's argument |
| Prediction or opinion | Marked as the author's own, not borrowed authority |

Claims with a number are the usual place a missing source hides; that is why the script looks for them.
