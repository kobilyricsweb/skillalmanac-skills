Required fields: initial_state or an explicit initial_entry_rule; approved_messages; audience_states; transition_rules; timing_constraints; exclusions; and terminal_conditions. The initial entry rule must state which audience state starts the sequence and the supplied condition or basis for entry. Each message needs an ID, purpose, and any stated prerequisite. Each state needs an ID and definition. Each transition rule must identify its ID, source state, destination state, and qualifying condition. Timing constraints should state delays, windows, or ordering requirements. Each exclusion should preserve its supplied text and, when stated, its scope, condition, and effect. Terminal conditions must identify the trigger, originating state or stated scope, and event that ends the sequence.

If a required field is missing, return the missing-input list and map only the supported portion. If the initial entry rule is missing, do not silently designate a state as the start; mark the affected path unresolved. If rules conflict, retain them, flag the affected branch, and avoid selecting a winner.

Every transition-bearing path row must record entry_state as its source, destination_state as its destination, entry_condition as the supplied initial or path-entry basis, cited_transition as the separate supplied rule ID, and transition_condition as that rule's qualifying condition. Do not substitute the rule ID, initial entry condition, or prior-state arrival for the operative transition condition. destination_state may be null only for unresolved or terminal rows. For rows with no transition, set transition_condition to null.

Represent every supplied exclusion in the exclusions collection. Preserve exclusion_text verbatim or faithfully, and record its supplied scope, condition, and effect; use null for an unstated scope or condition rather than inventing one. An exclusion is not a terminal condition merely because it prevents a message. Create a corresponding terminal path only when the input separately states that the exclusion ends the sequence.

Represent each terminal condition as its own path row with placement_status terminal, the originating state or stated scope in entry_state, its trigger in entry_condition, transition_condition set to null, and its effect in terminal_behavior. A terminal condition mentioned elsewhere does not replace this row.

Output collections are paths, exclusions, unplaced messages, unreachable states, conflicts, and open gaps. Include messages without supported placement, states without supported entry, every supplied exclusion, and explicit stop branches. Never add predicted engagement, inferred readiness, delivery actions, or unsupported reverse transitions.
