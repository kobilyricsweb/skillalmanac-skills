Required input fields are: target population definition; frame construction rules; frame date or time interval; included channels or units; explicit exclusions; known duplicate risks; and any stated coverage unknowns. Identify whether the frame is a snapshot, rolling period, or other supplied form. Missing target boundaries or frame dates limit the note and must be reported. The output must include: target definition; frame inclusion rules; observable exclusions; time bounds; duplicate risks and their stated mechanism; unknown coverage; conflicts; and verification findings. Key rules: inclusion in a frame does not establish representativeness; an exclusion rule does not quantify the excluded population; a duplicate risk does not prove duplicates occurred; and unknown coverage is not equivalent to zero coverage. Use only the supplied frame description and do not infer population size, bias magnitude, response quality, or statistical validity.
