# Outreach message rules

Applies to cold notes, referral requests, recruiter replies and follow-ups. The user sends every message themselves.

## Contents

- Hard rules
- Length limits and cadence
- Structure by message type
- Fill-in gaps instead of inventing

## Hard rules

1. **No fabricated connection.** Mention a mutual contact, shared school, event, article or prior conversation only if the user told you it is true in this conversation. If they supplied none, write the message without one.
2. **No fabricated interest.** Reference one specific, checkable fact about the company or role that the user has read (a post, a product, a job-post line). If the user has read nothing, ask them to read the job post and pick a line.
3. **No false urgency, flattery or pressure** ("I know you are busy but this is your last chance to hire me").
4. **No claims beyond the user's record.** Skills and numbers in a message must match the user's own story bank or their own words.
5. **One ask per message**, stated in the last sentence: a 15-minute call, a pointer to the right person, or a status update.
6. **Do not contact private individuals through scraped data.** Use a contact the user already has, a public work address or a professional profile page the user opened themselves. Do not build contact lists from scraped or leaked data.
7. **Do not mass-send.** Every message is written for one recipient; bulk templates with a swapped name are not drafted.

## Length limits and cadence

These are house working values, not platform rules; platforms set their own limits, so check the field before sending.

| Message | Limit |
|---|---|
| Connection note | 300 characters |
| Cold email or direct message | 120 words |
| Referral request to someone who knows the user | 150 words |
| Follow-up | 60 words |
| Thank-you after an interview | 100 words, sent within 24 hours |

Cadence for an application with no reply: first follow-up 7 to 10 days after applying, a second 7 days later, then stop and set the tracker status to `closed` with a note. A recruiter who has replied sets the pace; do not follow up faster than they asked.

## Structure by message type

| Type | Order |
|---|---|
| Cold note to a stranger | Who the user is in one clause; the one specific thing they read; the single ask; an easy exit ("no problem if not"). |
| Referral request | Why this role; one line of relevant proof from the story bank; what exactly the contact is asked to do; offer to send a short summary they can forward. |
| Follow-up | Reference the application with role and date; one new useful fact (a relevant project or answer to a question), not a repeat; one question. |
| Thank-you | One specific thing discussed; one sentence tying it to the user's relevant experience; confirm next step and date if known. |
| Decline or withdraw | Thank them; state the decision plainly; keep the door open without promising anything. |

## Fill-in gaps instead of inventing

When a required fact is missing, leave a visible placeholder such as `[name of the post you read]` and list the placeholders after the draft. Give two subject-line options at most. Never write "I hope this finds you well" as the opener; open with the reason for writing.
