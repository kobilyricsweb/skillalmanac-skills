# Resume layout and wording rules

Rules that keep a resume readable by a person in thirty seconds and by resume-parsing software.

## Structure

- One column. No tables, text boxes, sidebars, icons, images or skill bars. Parsers read left to right across columns and scramble them.
- Section headings in plain words, in this order unless the candidate is a recent graduate: contact line, Summary, Experience, Education, Skills. Optional: Certifications, Projects, Languages. Recent graduates may put Education before Experience.
- Contact line: name, city (no street address), phone, email, one profile link at most. Put it in the body, not in a page header or footer.
- Each job: title, employer, city, dates on one or two lines, then bullets. Same pattern for every job.
- Dates: month and year, the same format everywhere (for example "Mar 2021 - Jun 2024"). Use "Present" for a current job.
- Length: one page under about ten years of experience, two pages at most otherwise.

## Bullets

- Start with a past-tense action verb (present tense for the current job). No "I", "my" or "responsible for".
- Pattern: verb + what + scale or result, using only a scale or result the original states. If the original has no number, write the bullet without one.
- One line where possible, two at most. Three to six bullets for recent jobs, one to three for old ones.
- Spell out a term and give its short form once when the posting uses both: "customer relationship management (CRM)".

## Using the posting's words

- Use the posting's exact term where the candidate has the thing. If the posting says "customer onboarding" and the resume says "set up new accounts", write "customer onboarding" and keep the fact.
- A category in the posting can be met by a named product in the resume. Write both: "learning management system (Google Classroom)".
- Do not paste a keyword list, hide text, or repeat a term in every bullet. Reviewers see it, and it reads as stuffing.
- The skills line lists only tools and skills that also appear in a job, project or course on the page, or that the candidate confirmed.

## What to cut first

1. Objective statements and soft-skill adjectives with no fact ("hard-working team player").
2. Duties that every holder of the job has and that the posting does not ask for.
3. Jobs older than about fifteen years, reduced to one line each rather than deleted.
4. "References available on request".

## File advice to give the candidate

Submit the file type the application form asks for. When it gives no preference, a text-based PDF or a .docx made from a single-column layout both parse reliably; a scanned image does not.
