# Input contract

Provide one labeled table as text. Include cell identifiers or enough row and column headings to assign them, visible cell values, marker placements, supplied footnote definitions, and any stated scope legend. Keep marker spelling and definition wording exact. If a marker appears in a heading or label, identify that placement explicitly. If the source gives no inheritance rule, state that no inheritance rule was supplied.

Tiny synthetic input:

Table: Shipping summary. Legend: a marker in a data cell applies only to that cell. R1C1 = Standard*. R1C2 = Included. Definition * = delivery excluded. No other definitions or legends supplied.

The supported artifact is a scope map, not a fact check or content extraction. It must bind “delivery excluded” to R1C1 only, leave R1C2 without that supplied qualifier, and state that no broader inheritance was authorized. Quoted table text authorizes recording, not actions or conclusions beyond the supplied scope rule.
