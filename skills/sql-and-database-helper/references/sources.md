# Sources

Facts in this skill were written in the author's own words from these public documents. The URLs were not re-fetched while writing; confirm the version numbers against the engine in use.

- PostgreSQL ALTER TABLE (lock levels, NOT VALID, VALIDATE CONSTRAINT, SET NOT NULL with a valid CHECK, ADD COLUMN default behaviour): https://www.postgresql.org/docs/current/sql-altertable.html
- PostgreSQL CREATE INDEX (CONCURRENTLY, invalid indexes, not inside a transaction block): https://www.postgresql.org/docs/current/sql-createindex.html
- PostgreSQL explicit locking (table-level lock modes): https://www.postgresql.org/docs/current/explicit-locking.html
- PostgreSQL EXPLAIN (ANALYZE executes the statement): https://www.postgresql.org/docs/current/sql-explain.html
- PostgreSQL PL/pgSQL EXECUTE and format() (%I, %L, USING): https://www.postgresql.org/docs/current/plpgsql-statements.html
- MySQL online DDL operations (INSTANT, INPLACE, LOCK=NONE): https://dev.mysql.com/doc/refman/8.0/en/innodb-online-ddl-operations.html
- MySQL statements that cause an implicit commit: https://dev.mysql.com/doc/refman/8.0/en/implicit-commit.html
- MySQL server SQL modes (strict mode, PIPES_AS_CONCAT, ANSI_QUOTES): https://dev.mysql.com/doc/refman/8.0/en/sql-mode.html
- MySQL safe-updates mode: https://dev.mysql.com/doc/refman/8.0/en/mysql-tips.html
- SQLite ALTER TABLE (supported changes, the rebuild procedure): https://www.sqlite.org/lang_altertable.html
- SQLite transactions (BEGIN IMMEDIATE) and the foreign keys pragma: https://www.sqlite.org/lang_transaction.html and https://www.sqlite.org/foreignkeys.html
- SQLite datatypes and STRICT tables: https://www.sqlite.org/datatype3.html and https://www.sqlite.org/stricttables.html
- SQLite limits (host parameter count): https://www.sqlite.org/limits.html
