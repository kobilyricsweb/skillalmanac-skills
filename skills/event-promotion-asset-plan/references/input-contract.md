Required fields:

- event_facts: confirmed event name, format, date, time, location or access method, and any confirmed benefits.
- approved_audience: audience description or explicit audience limits.
- confirmed_schedule: confirmed event and registration dates, plus any relevant milestones when registration applies.
- speaker_permissions: each speaker’s approved name, likeness, quote, and channel scope.
- channel_list: channels allowed for the requested asset set.
- production_milestones: supplied deadlines or ordering constraints.

If any required field is missing, produce a partial plan with the missing field listed as a blocker when it is needed for the requested artifact. Registration facts and milestones are required only when the supplied event process or a proposed artifact depends on registration. If registration is explicitly not applicable, record that; if its applicability is unclear, ask an open question without automatically blocking unrelated assets. Do not infer a date, speaker permission, benefit, audience, or channel. Output must include an asset table, dependencies, deadline relations, placeholders, and blocked items. Preserve conflicts rather than choosing one version. A plan is not production or publication authorization. Keep channel-specific permissions explicit and use only confirmed facts.
