# Skill Almanac skills

Open skill packages for coding agents, scored at [skillalmanac.com](https://skillalmanac.com).

Each folder under `skills/` is one self-contained skill in the open Agent Skills format: a `SKILL.md` with YAML frontmatter, a `LISTING.md` (what it does and its limits), `evals/` (the tests used to evaluate it), and optional `scripts/` and `references/`. Everything is Apache-2.0.

- **Index:** [`catalog.json`](catalog.json) lists every skill (slug, name, one line, category, page on the site). It is generated by `tools/build_catalog.cjs`.
- **Scores:** every skill has a page at `https://skillalmanac.com/skills/skill-almanac/<slug>` with its Platform Score and the evidence behind it.
- **Method:** the scoring method is published at [skillalmanac.com/methodology](https://skillalmanac.com/methodology).

Many packages were drafted with AI assistance. Each `LISTING.md` states who wrote it and whether a human has reviewed it.

## Install a skill

All four tools read the same folder. Pick a skill (here `action-title-rewriter`) and copy its folder into the tool's skills directory:

```bash
git clone --depth 1 https://github.com/kobilyricsweb/skillalmanac-skills.git
cd skillalmanac-skills
cp -r skills/action-title-rewriter ~/.claude/skills/        # Claude Code, global
# project-local instead: cp -r skills/action-title-rewriter .claude/skills/
# Codex CLI: ~/.codex/skills/   Cursor: .cursor/skills/   Gemini CLI: ~/.gemini/skills/
```

Check your tool's current documentation for the exact skills directory, since it changes between versions. Then ask the agent for the task the skill describes; the `description` in `SKILL.md` tells the agent when to use it. Read a skill's `SKILL.md` and `scripts/` before installing it.

## Report a problem

Open an [issue](https://github.com/kobilyricsweb/skillalmanac-skills/issues) with the skill slug, what you asked, what happened, and the agent and version. Security concerns: use the issue tracker too, but leave out exploit details and say only that it is a security report; we will reply with a private channel.
